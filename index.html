Dashboard

Overview of staff, leave, overtime and advances.

Employees

Manage your staff records.

Leave Management

Full day = 1 day, half day = 0.5 day.

Employee OT

Overtime hours — decimals like 1.5, 2.5 or 3.75 are supported. OT on a holiday is counted and marked "Holiday".

Advances

Monthly and employee-wise totals are calculated automatically.

Holidays

Set weekly holidays and special holiday dates. Work and leave are not counted on holidays. OT is counted and marked as Holiday.

Outside Workers

Kept completely separate from company employees.

Outside Worker Work

Record the days outside workers worked — one day at a time, or many days at once. Full day = 1, half day = 0.5.

Outside Worker Leave

Leave of outside workers — the same records also appear on the Leave page. A worker cannot have work and leave on the same day.

Outside Worker OT

Separate overtime records for outside workers.

Activity & Last Updated

Recorded automatically. This page is read-only and cannot be edited.

Monthly Reports

Employee-wise and outside-worker reports. Print or export to CSV.

Backup & Google Drive

Your data lives only in this browser. Back it up regularly.

Backup / Restore

Export downloads ameer-fire-safety-backup-YYYY-MM-DD.json. Import replaces all data in this browser with the contents of the file.

Login & Security

The login username is fixed. Change the password here (current password needed). If you forget it, use Forgot password? on the login screen — it asks the developer security questions.

This is a screen lock for a frontend-only app: it keeps casual users out but is not bank-grade security. The login is stored only in this browser and is not part of the JSON backup.

Google Drive

Manual process. This app does not connect to Google Drive and cannot upload or read files automatically. The buttons below download the backup and open your Drive folder so you can upload or download the file yourself.

Open Drive folder

Export to Drive

  1. Click Export to Drive. The JSON backup downloads automatically.
  2. The Drive folder opens in a new tab.
  3. Drag the downloaded file into that folder.

Import From Drive

  1. Click Import From Drive. The Drive folder opens in a new tab.
