Backup / Restore

Export downloads ameer-fire-safety-backup-YYYY-MM-DD.json. Import replaces all data in this browser with the contents of the file.

Google Drive

Manual process. This app does not connect to Google Drive and cannot upload or read files automatically. The buttons below download the backup and open your Drive folder so you can upload or download the file yourself.

Open Drive folder

Export to Drive

  1. Click Export to Drive. The JSON backup downloads automatically.
  2. The Drive folder opens in a new tab.
  3. Drag the downloaded file into that folder.

Import From Drive

  1. Click Import From Drive. The Drive folder opens in a new tab.
