# Ameer Fire and Safety — Employee, Leave, OT & Advance Management

A free, frontend-only web app (HTML + CSS + vanilla JavaScript). No backend, no database, no build step.
All data is stored in your browser's `localStorage`.

## Files

- `index.html` — page structure
- `style.css` — styles (white UI, fire red & fire yellow)
- `app.js` — all app logic

## Run locally

Double-click `index.html`. That's it.

## Deploy on GitHub Pages

1. Create a new GitHub repository.
2. Upload `index.html`, `style.css` and `app.js` to the repository root.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then **Save**.
5. After a minute your app is live at `https://<your-username>.github.io/<repo-name>/`.

## Important notes

- Data lives **only in the browser and device** you use (and per website address). A different browser, device, or address shows an empty app.
- Clearing site data / browsing history can erase it. **Export a JSON backup regularly** (Backup & Drive page).
- To move data to another device: export on the old device, import on the new one.
- Google Drive is a manual process: the app downloads the backup and opens your Drive folder; you upload / download the file yourself. There is no automatic Google sync.
